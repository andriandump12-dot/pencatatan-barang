# StockLog V4 — Activity Log

V4 menambahkan Activity Log untuk Admin. Database membuat log otomatis saat data stock_entries INSERT/UPDATE/DELETE. Admin dapat melihat hingga 100 aktivitas terbaru dan menerima pembaruan realtime.

Jalankan `supabase-activity-log.sql` di Supabase SQL Editor, lalu upload `index.html`, `app.js`, dan `styles.css` ke branch `main` GitHub.
